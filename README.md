# Air Drop Height Calculator

A simple calculator that estimates the height of a building (or any drop point) using free-fall time.

## 🔗 Live Demo
Try it here: [Air Drop Height Calculator](https://claude.ai/artifact/QsUTbnKjQEueDzLkzmv9dW)

## 📐 How It Works
Drop a small, dense object (like a stone or bolt) from the top of the building and time how long it takes to hit the ground. Then the height can be estimated using the free-fall formula:

h = 1/2 * g * t²
h = 4.9 * t²   (using g = 9.8 m/s²)

Where:
- h = height (in meters)
- t = time taken to fall (in seconds)
- g = acceleration due to gravity (9.8 m/s²)

## ✅ Conditions for Accuracy
- The object must be dropped, not thrown.
- Use a small, dense object to minimize air resistance.
- Time the fall as precisely as possible — slow-motion video works better than a manual stopwatch.
- Taller drops give more accurate results, since timing error matters less relative to total fall time.
